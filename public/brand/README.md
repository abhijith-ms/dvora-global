# DVORA brand assets

`source/dvora-approved-logo-original.png` is the approved supplied artwork. Keep it as the reference source; do not overwrite it.

## Website marks

- `logo-horizontal.png` — primary transparent navy navigation/logo mark.
- `logo-horizontal-white.png` — transparent reversed mark for navy or dark imagery.
- `logo-horizontal-tagline.png` — primary transparent lockup with “Your future. Beyond Borders.”
- `logo-horizontal-tagline-white.png` — reversed tagline lockup.
- `logo-stacked.png` and `logo-stacked-tagline.png` — portrait lockups for narrow placements.
- `logo-icon.png` and `logo-icon-white.png` — book symbol only.

## Browser and sharing assets

- `favicon/favicon-16.png`, `favicon/favicon-32.png`, and `favicon/favicon.ico` — browser favicons.
- `favicon/favicon-192.png` and `favicon/favicon-512.png` — Android/PWA icons.
- `favicon/apple-touch-icon.png` — Apple touch icon.
- `social/social-card.png` — 1200 × 630 Open Graph/social-share image.

Use navy marks on light surfaces and the white variants only on dark, high-contrast surfaces. Keep the transparent PNGs on the page; do not use the square source artwork in navigation.
